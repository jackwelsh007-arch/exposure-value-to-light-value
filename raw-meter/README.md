## 🔍 The Core Essence

> [!NOTE]
> **Key Takeaway:** A true RAW exposure meter computes the **RAW ETTR Signal Deviation ($\Delta y_{\text{ETTR}}=y_{\text{peak}}-y_{\text{sat}}$)** to measure the exact linear distance between the sensor's fixed physical saturation limit ($y_{\text{sat}}$) and the peak signal generated by the brightest color channel in the scene ($y_{\text{peak}}$).

* **Input-Driven Physics:** Traditional meters calculate light to achieve an arbitrary 18% mid-gray output. This model evaluates raw data strictly at the sensor level based on physical capacity.
* **Effective Headroom Tracking:** The digital saturation ceiling ($y_{\text{sat}}$) remains a fixed hardware constant. Increasing analog gain ($sv_{\text{raw}}$) reduces effective headroom, driving the peak signal faster against that unmovable wall.
* **SNR Maximization:** By mathematically tracking the exact RAW signal deviation ($\Delta y_{\text{ETTR}} = 0$), the peak-driven approach maximizes the signal-to-noise ratio while flawlessly protecting highlights from clipping.
* **The Seamless Workflow:** By decoupling sensor physics from visual intent through an adjustable artistic bias ($EC_{\text{user}}$), the framework bridges the gap between pure hardware optimization and a seamless, rapid in-camera metering workflow.
